# Safer Driver Training

Website for Safer Driver Training, a driving instructor based in Eccleshall, Staffordshire.

Static site — no build step. `index.html` is self-contained (fonts, photos and the coverage map are inlined), so it deploys as-is to Cloudflare Pages with no build command and no output directory other than the repo root.

Currently a first-pass design concept, not the final site.
